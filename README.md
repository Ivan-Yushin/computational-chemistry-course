# Современные методы вычислительной химии — материалы курса

Полные материалы курса по квантовой химии, молекулярной динамике и машинному
обучению в химии: лекции, практические ноутбуки, домашние работы и данные.

## Структура

```
.
├── Занятия/
│   └── Занятие_N/
│       ├── Занятие_N.ipynb                   # разбираем на паре
│       ├── Занятие_N_Домашняя_работа.ipynb   # домашнее задание
│       └── *.csv                             # данные к занятию
```

Материалы выкладываются по ходу семестра — новые появляются в репозитории к соответствующему занятию.
